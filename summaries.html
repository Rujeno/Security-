الوحدة 1 — أساسيات الشبكات

Explaining Network Topologies — Networking Overview · OSI Model · SOHO Networks · Troubleshooting Methodology

مفهوم الشبكة وأنواعها

  • الشبكة (Network): أجهزة متصلة عبر transmission medium (نحاس، ألياف، لاسلكي) لمشاركة الموارد والتواصل.
  • Peer-to-Peer: كل جهاز client وserver معًا، بلا مركز — مناسب للشبكات الصغيرة فقط.
  • Client-Server: server مركزي يقدّم الخدمات — النموذج المعتمد في الشركات.
  • LAN حسب الحجم: SOHO (منزل/مكتب صغير) · Enterprise LAN (مبنى/حرم) · Datacenter (سيرفرات بكثافة عالية).

هيكليات الشبكة — Topologies

  • Point-to-Point: عقدتان فقط؛ Half-duplex (تناوب) مقابل Full-duplex (متزامن).
  • Star: كل عقدة تتصل بـconcentrator مركزي (Hub يكرر للجميع / Switch يوجّه انتقائيًا)؛ العيب: single point of failure.
  • Mesh: Full mesh = روابط n(n−1)/2، Partial mesh أكثر عملية؛ الميزة مرونة عالية (resilience) عند فشل روابط.

نموذج OSI — الطبقات السبع

  • 7 طبقات: عند الإرسال encapsulation (7→1)، عند الاستقبال de-encapsulation (1→7). Mnemonic: Please Do Not Throw Sausage Pizza Away.
  • وحدات البيانات: L1=Bits، L2=Frames، L3=Packets، L4=Segments.
  • الأجهزة: Hub→L1، Switch/Bridge/NIC/AP→L2، Router/ACL→L3، Multilayer switch/Firewall/IDS→L4.
  • تقسيم المسؤولية: L1–3 = Network، L4–7 = Host.

SOHO Router

  • L1: منافذ RJ-45، هوائيات واي فاي، منفذ WAN لـISP.
  • L2: يعمل كـEthernet switch + Wireless AP على نفس الشبكة المحلية.
  • L3: يشغّل DHCP server ويوجّه بين الشبكة المحلية والإنترنت؛ واجهة WAN تأخذ public IP.

الأرقام الثنائية — Binary

  • 8 bits لكل octet بالأوزان: 128-64-32-16-8-4-2-1.
  • مثال: 205 = 1100 1101، 132 = 1000 0100.

منهجية استكشاف الأخطاء — 7 خطوات

  • 1) Identify the problem: جمع معلومات، أسئلة مفتوحة/مغلقة، تكرار المشكلة، ماذا تغيّر.
  • 2) Establish theory: Top-down، Bottom-up (تحقق من الكيبل أولًا)، أو divide-and-conquer.
  • 3) Test theory — صعّدي (Escalate) إذا تجاوزت المشكلة صلاحيتك أو الجهاز تحت ضمان.
  • 4–7) خطة عمل → تنفيذ → تحقق من الحل → توثيق النتائج.
اربطي كل طبقة OSI بوحدة بياناتها وجهازها (Hub=L1/Bits، Switch=L2/Frames، Router=L3/Packets) — وتذكري: "single point of failure" = Star، "resilience/redundant paths" = Mesh.

MODULE 2

الوحدة 2 — الكيابل والتركيب الفيزيائي

Supporting Cabling and Physical Installations — Ethernet · Copper & Fiber Cabling · Structured Cabling · Physical Install · Cable Troubleshooting

Ethernet ومصطلحات نقل البيانات

  • IEEE 802.3: معايير Ethernet النحاسية — 10Base-T (10 Mbps, UTP)، 1000Base-T (Gigabit, Cat6)، 10GBase-T (10 Gbps).
  • معايير Fiber: 100Base-FX/SX (MMF, 100 Mbps)، 1000Base-SX/LX (1 Gbps)، 10GBase-SR (10 Gbps).
  • CSMA/CD: الاستماع قبل الإرسال على وسيط مشترك؛ عند التصادم: Jam signal + انتظار عشوائي ثم إعادة إرسال.

الكيابل النحاسية والموصلات

  • UTP: بلا تدريع، حماية EMI ضعيفة، اقتصادي — STP: تدريع موصل يقلل EMI وcrosstalk.
  • RJ11 (هاتف، 6P4C) مقابل RJ45 (شبكات، 8P8C، حتى 10 Gbps).
  • Plenum (مقاوم حريق، فوق الأسقف) مقابل Riser (رأسي بين الطوابق، أرخص).
  • Coaxial (TV/CCTV) مقابل Twinaxial (10GB Ethernet، مسافات قصيرة جدًا).

تنفيذ التمديدات — Structured Cabling

  • Work Area → Horizontal Cabling → Telecommunications Room (IDF) → Backbone Cabling → Demarc.
  • T568A/T568B: استخدمي نفس المعيار بالطرفين للكيبل المستقيم.
  • Patch Panels: خلف = punch down (IDC)، أمام = منافذ RJ45.

الألياف البصرية — Fiber Optic

  • التكوين: Core → Cladding → Buffer؛ سرعات حتى 800 Gbps ومناعة كاملة ضد EMI.
  • Single Mode: core صغير، توهين أقل، مسافات طويلة. Multimode: core أكبر، مسافات قصيرة.
  • موصلات: SC (2.5mm)، LC (1.25mm، الأصغر)، ST (bayonet).
  • WDM: BiDi · CWDM (حتى 16 قناة) · DWDM (20/40/80/160 قناة).

عوامل التركيب الفيزيائي

  • Rack: مقاس EIA 19"؛ مراقبة حرارة/رطوبة لمنع التكاثف والتآكل.
  • PDU: توزيع طاقة نظيفة؛ UPS: استمرارية عند الانقطاع.
  • إخماد الحريق: Class C للحرائق الكهربائية.

استكشاف أخطاء الكيابل

  • Throughput (فعلي) مقابل Goodput (Application)؛ Attenuation = فقدان قوة الإشارة بالـdB.
  • أدوات: Cable Tester، Wire Map Tester، Tone Generator+Probe، Loopback Tool.
  • Crosstalk: NEXT عند طرف المرسل، FEXT عند المستقبل، Alien Crosstalk من كيابل مجاورة.
فرّقي بسرعة: نهاية المرسل = NEXT، عند المستقبل = FEXT، من كيابل مجاورة = Alien Crosstalk، وفقدان الإشارة مع المسافة = Attenuation.

الوحدة 3 — الواجهات والسويتشات

Configuring Interfaces and Switches — Network Interfaces · Ethernet Switches · Switch Port Configuration · Switch Troubleshooting

واجهات الشبكة — Network Interfaces

  • NIC: transceiver يربط المضيف بالوسيط، له MAC فريد، يعمل بـData Link (L2).
  • MAC Address: 48-bit hex = OUI (الشركة المصنّعة) + Device ID؛ Broadcast = FF:FF:FF:FF:FF:FF.
  • Ethernet Frame: Preamble/SFD → Destination MAC → Source MAC → EtherType → Payload → FCS.

سويتشات الإيثرنت

  • Hub (L1): يبث لكل المنافذ بدون ذكاء توجيه.
  • Bridge: يفصل segments فيزيائية لكن يبقي الأجهزة بنفس الشبكة المنطقية.
  • Switch (L2): يتعلم MAC ويوجّه لمنفذ الوجهة فقط.

إعداد منافذ السويتش

  • Link Aggregation/NIC Teaming: دمج عدة روابط بقناة منطقية واحدة → redundancy.
  • MTU: الإطار العادي 1500 بايت؛ Jumbo frame حتى 9216 بايت.
  • STP: يمنع bridge loops ويوفر fault tolerance؛ PoE: بيانات وطاقة بكيبل واحد.

استكشاف أخطاء السويتش

  • مؤشرات المنفذ: أخضر ثابت=متصل، أخضر وامض=ترافيك، بلا إضاءة=معطل، كهرماني=محظور/عطل.
  • حالات المنفذ: Down/down، Administratively down (يدوي)، error disabled (تلقائي).
  • أخطاء شائعة: CRC، Runt (إطار صغير جدًا)، Giant (إطار كبير جدًا).
  • Network Loops → يحلها STP؛ Broadcast Storms → مراقبة DHCP وتقسيم الشبكة.
Hub يبث للجميع (L1) · Bridge يفصل segments لكن نفس الشبكة المنطقية · Switch يوجّه بذكاء حسب MAC (L2)؛ STP هو الحل المعياري لمنع حلقات الشبكة.

الوحدة 4 — عنونة الشبكات

Configuring Network Addressing — IP Basics · IPv4 Addressing · Subnetting/CIDR/VLSM · IP Troubleshooting Tools · IPv6 · IP Troubleshooting

أساسيات بروتوكول الإنترنت

  • ARP: يربط عنوان IP بعنوان MAC المقابل على الشبكة المحلية.
  • Unicast: لوجهة واحدة. Broadcast: لكل المضيفين. Multicast: لمجموعة محددة. Anycast: لأقرب عضو من مجموعة.

عنونة IPv4 والتقسيم الفرعي

  • عنوان IPv4 = 4 octets × 8 bits = 32 bit؛ Network ID مقابل Host ID.
  • Subnet Mask يحدد جزء الشبكة — مثال 192.168.1.x /255.255.255.0: أول 24 bit للشبكة.
  • مدى Private: Class A 10.0.0.0/8، Class B 172.16.0.0/12، Class C 192.168.0.0/16.
  • Borrowing bits: استعارة بت من Host تزيد الشبكات الفرعية وتقلل المضيفين، مثال /24→/25→/26.
  • CIDR: تخصيص عناوين بلاحقة suffix؛ VLSM: subnets بأحجام مختلفة بنفس الشبكة.

أدوات فحص IP

  • ipconfig /all, /renew, /release (ويندوز) مقابل ip addr, ip link (لينكس).
  • arp -a (عرض cache)، arp -s (إضافة)، arp -d (حذف).

IPv6

  • hex (8 مجموعات × 16-bit)؛ أول 64 bit للشبكة، الـ64 الأخرى للمضيف.
  • Global Unicast (public) مقابل Link Local fe80::/10 (private).
  • انتقال: Dual Stack، Tunneling، NAT64.

استكشاف أخطاء IP

  • Duplicate IP: Windows يعطّل العنوان تلقائيًا؛ تشخيص بـping + arp -a.
  • Duplicate MAC: قد يشير لهجوم spoofing.
  • تسلسل ping: loopback (127.0.0.1) → host المحلي → gateway → مضيف بعيد → hostname.
تسلسل تشخيص IP الأهم: ping loopback ← host المحلي ← default gateway ← مضيف بعيد — وICMP قد يكون محجوبًا بجدار ناري فلا يعني الفشل عطلًا حقيقيًا.

الوحدة 5 — التوجيه والسويتشنج المتقدم

Configuring Routing and Advanced Switching — Routing Technologies · Dynamic Routing · NAT · Firewalls · Enterprise Topologies · VLANs

تقنيات التوجيه

  • جدول التوجيه: Protocol, Destination, Interface, Gateway/Next hop.
  • أنواع المسارات: Directly connected، Remote، Host، Default route.

بروتوكولات التوجيه الديناميكي

  • RIP: hop count بحد أقصى 15، تقارب بطيء.
  • EIGRP: ملكية Cisco، distance-vector متقدم، يدعم IPv4/IPv6.
  • OSPF: link-state، خوارزمية Shortest Path First.
  • BGP: يربط autonomous systems على الإنترنت، path vector، يدعم CIDR.

NAT والجدران النارية

  • Dynamic NAT: pool عناوين خارجية؛ Static NAT: عنوان ثابت يسمح باتصال وارد؛ PAT: عنوان عام واحد لعدة أجهزة عبر أرقام المنافذ.
  • Stateless (Packet Filtering): يرشّح IP/بروتوكول/منفذ فقط — Stateful: يتتبع حالة الاتصالات، أنسب للشركات.

هيكليات المؤسسات والـVLANs

  • 3-Tiered Hierarchy: core/distribution/access لتحقيق redundancy وfault tolerance.
  • VLAN: شبكات معزولة منطقيًا فوق عتاد فيزيائي واحد؛ تحتاج Inter-VLAN routing للتواصل بينها.
  • Native VLAN (يستقبل untagged) · Voice VLAN · Management VLAN؛ Trunking ينقل عدة VLANs بين السويتشات.
جداول التوجيه = خرائط الراوتر الداخلية؛ NAT يترجم بين عناوين خاصة وعامة؛ VLANs تُنشئ أجزاء منطقية داخل شبكة فيزيائية واحدة.

الوحدة 6 — تطبيق خدمات الشبكة

Implementing Network Services — Transport Protocols · DHCP · APIPA/SLAAC · DHCP Relay · DNS

بروتوكولات Transport

  • TCP: نقل موثوق؛ Three-Way Handshake: SYN → SYN+ACK → ACK.
  • UDP: غير مضمون، بلا handshake، أخف وأسرع.

DHCP

  • عملية DORA: Discover → Offer → Request → Ack.
  • Reservations: IP ثابت مربوط بـMAC. Exclusions: نطاق محجوز لا يوزَّع.

APIPA وSLAAC

  • APIPA: تعيين ذاتي عند غياب DHCP، ضمن 169.254.0.1–169.254.254.255.
  • SLAAC (Stateless، لا يوفر DNS) مقابل DHCPv6 (Stateful، تحكم مركزي).
  • DHCP Relay Agent / IP Helper: يمرر طلبات DHCP عبر حدود الـsubnet.

DNS

  • هرمية: Root → TLD → Domain → Sub-Domain.
  • سجلات: A (اسم↔IPv4)، MX (بريد)، SRV، TXT (SPF/DKIM)، PTR (بحث عكسي).
  • أمان DNS: DNSSEC، DoT، DoH.
DHCP يوزّع IP/subnet/gateway/DNS تلقائيًا عبر DORA؛ DNS ترجمة هرمية عالمية من أسماء لعناوين IP؛ تحقّق أخطاء DNS بالترتيب: local cache → HOSTS → nslookup/dig.

الوحدة 7 — خدمات التطبيقات

Explaining Application Services — TLS/NTP/PTP · Web/File/Database Services · Email/Voice · Disaster Recovery & HA

أمان التطبيقات ومزامنة الوقت

  • TLS Handshake: Client Hello → Server Hello → Key Exchange → Session Key.
  • NTP: منفذ UDP 123، هرمية stratum؛ PTP: دقة أعلى (صناعي/5G).

خدمات الويب والملفات وقواعد البيانات

  • HTTP (Port 80) مقابل HTTPS (Port 443، تشفير TLS).
  • FTP (Port 20/21، بلا تشفير) مقابل SFTP (Port 22، مشفّر).
  • RDBMS (schema محددة، vertically scalable) مقابل NoSQL (بلا schema، horizontally scalable).

خدمات البريد والصوت

  • SMTP: منافذ 25/465/587. IMAP: إدارة/مزامنة البريد.
  • VoIP: RTP (وسائط) + RTCP (إحصائيات)؛ SIP (منفذ 5060/5061 TLS).

التعافي من الكوارث والتوفر العالي

  • RPO: أقصى فقدان بيانات مقبول (قبل الكارثة) — RTO: زمن استعادة الخدمة (بعد الكارثة).
  • مواقع التعافي: Cold → Warm → Hot Site (أسرع/أغلى).
  • MTBF/MTTR: متوسط الوقت بين الأعطال / للإصلاح؛ Load Balancers وHA Clusters تقلل التوقف.
First Hop Redundancy (HSRP/VRRP) يبدّل تلقائيًا لبوابة احتياطية عند فشل الأساسية لمنع single point of failure.

الوحدة 8 — دعم إدارة الشبكة

Supporting Network Management — Policies & Documentation · Discovery & Monitoring · SNMP · Event Management · Packet Capture · Traffic Monitoring

التوثيق وإدارة التغيير

  • أنواع التوثيق: Configuration, Backup, Change, Asset, Network management.
  • Change Management: قوالب موحدة، version control، مراجعة دورية.

اكتشاف الأجهزة والمراقبة

  • أدوات: Nmap, AngryIP, PRTG؛ CDP (Cisco فقط) مقابل LLDP (معيار عام).
  • Performance Monitoring: خط أساس (baseline) وتنبيهات عند تجاوز العتبات.

SNMP

  • منفذا UDP 161/162؛ مكونات: Manager (NMS)، Agent، MIB.
  • SNMPv2c ضعيف (نصي) مقابل SNMPv3 (تشفير ومصادقة قوية).

إدارة الأحداث

  • Syslog: منفذ UDP 514، مستويات شدة من 0 Emergency إلى 7 Debug.
  • SIEM = SIM + SEM: تجميع سجلات وربط أحداث وتنبيه لحظي.

التقاط الحزم ومراقبة الترافيك

  • أدوات: tcpdump, Wireshark, ngrep؛ Follow TCP Stream لإعادة تركيب الجلسة.
  • Flow Data: IP مصدر/وجهة، حجم الحزم، الطوابع الزمنية؛ Traffic Shaping (QoS) لأولوية التطبيقات الحرجة.
Nmap وCDP/LLDP يحددان الأجهزة؛ SNMP يراقب/يضبط عن بُعد؛ السجلات وSIEM يحللان الأحداث الأمنية؛ التقاط الحزم يشخّص مشاكل الأداء.

الوحدة 9 — مفاهيم أمان الشبكة

Explaining Network Security Concepts — CIA Triad · Threats & Attacks · Spoofing · Rogue Systems · Social Engineering

مفاهيم الأمان

  • CIA Triad: Confidentiality، Integrity، Availability.
  • الثغرات: Zero-Day (الأخطر، تُستغل قبل التحديث)؛ حالات البيانات: at Rest، in Transit، in Use.

تهديدات وهجمات الشبكة

  • DoS/DDoS: ICMP Flood, SYN Flood, DNS Amplification — عبر Botnets.
  • Malware: Viruses/Worms, Trojan, PUP/PUA؛ Fileless Malware يقيم بالذاكرة وصعب الاكتشاف.

Spoofing وRogue Systems

  • On-Path Attacks (MITM): اعتراض/تعديل اتصال دون اكتشاف (session hijacking, DNS spoofing).
  • MAC Flooding: إغراق جدول CAM؛ VLAN Hopping: عبر Switch Spoofing أو Double Tagging.
  • Rogue DHCP Server: يوزّع إعدادات خاطئة ويهيّئ لهجمات on-path.

الهندسة الاجتماعية

  • تستغل الثغرات البشرية: Shoulder Surfing، Dumpster Diving، Tailgating، Phishing.
  • Dictionary Attack (كلمات قاموس) مقابل Brute Force (كل التركيبات).
Honeypots وHoneynets تُستخدم لاستدراج المهاجمين واكتشافهم مبكرًا؛ وعي المستخدمين هو خط الدفاع الأول.

الوحدة 10 — تطبيق ميزات أمان الشبكة

Applying Network Security Features — Authentication · Authorization & Account Management · Network Hardening · Switch Security · Security Rules

المصادقة

  • AAA: Identity ← Authentication ← Authorization ← Accounting.
  • SSO/Kerberos: دخول واحد عبر tickets بدل تكرار بيانات الدخول.

التفويض وإدارة الحسابات

  • DAC (مالك المورد يتحكم) مقابل RBAC (حسب الدور الوظيفي).
  • Least Privilege وSeparation of Duties؛ الحسابات المميزة تحتاج PAM.

تحصين الشبكة

  • Defense in Depth: Data ← Application ← Host ← Internal Network ← Perimeter ← Physical ← Policies.
  • تحديث النظام، إغلاق المنافذ غير الضرورية، تغيير بيانات الدخول الافتراضية.

أمان السويتش وقواعد الأمان

  • NAC، MAC Filtering، DHCP Snooping، مصادقة 802.1x (EAP).
  • Firewalls (ACL + stateful inspection) وProxy Servers لتصفية المحتوى؛ تجنّب غياب implicit deny.
AAA + DAC/RBAC + Least Privilege يضمن وصول المصرّح لهم فقط؛ Defense in Depth يحمي CIA عبر طبقات متعددة.

الوحدة 11 — دعم تصميم أمان الشبكة

Supporting Network Security Design — Zone-Based Security · Internet of Things · Physical Security

الأمان القائم على المناطق

  • أربع مناطق: Private Security، Private Client، Guest، Public Server.
  • Screened Subnet / Perimeter Network: منطقة عازلة بين External Router وInternal Router تستضيف سيرفرات عامة.
  • IDS يراقب وينبّه فقط، بينما IPS يوقف الهجوم فورًا.

إنترنت الأشياء

  • ICS يدير أتمتة العمليات الصناعية؛ SCADA يركّز على جمع البيانات والتحكم اللحظي.
  • NB-IoT (LTE منخفض الطاقة) مقابل LTE-M (حتى 1 Mbps).
  • الحل الأمني الأهم: Segmentation لأجهزة IoT ضعيفة الحماية.

الأمان الفيزيائي

  • Electronic Locks، Badge Reader، Biometric Locks، Secure Cabinets.
  • كاميرات: Fixed (نقاط دخول) مقابل PTZ (تغطية واسعة وتتبع).
Geofencing: حد افتراضي جغرافي عبر GPS/IPS للمصادقة الواعية بالسياق، يُدار غالبًا عبر MDM.

الوحدة 12 — إعداد الشبكات اللاسلكية

Configuring Wireless Networks — Wireless Standards · Enterprise Design · Wireless Security · Wireless Troubleshooting

معايير الشبكات اللاسلكية

  • 802.11: MAC يستخدم CSMA/CA؛ 802.11ac/Wi-Fi 5 (5GHz فقط، Gigabit).
  • MU-MIMO: إرسال لعدة محطات بآن واحد؛ Band Steering: توجيه لنطاق أقل ازدحامًا.

تصميم شبكات المؤسسات

  • BSSID = نقطة وصول واحدة؛ ESSID = اسم شبكة يجمع عدة BSS.
  • RSSI بـdBm (الأقرب لـ0 أفضل، أقل من -80dBm = فقدان حزم).
  • Wireless Controllers: إدارة مركزية للـAPs وتعيين VLANs تلقائيًا.

أمان الشبكات اللاسلكية

  • WPA2 (AES) مقابل WPA3 (تشفير فردي لكل جهاز، Forward Secrecy).
  • Rogue AP / Evil Twin: نقطة وصول مزيّفة بنفس SSID لاعتراض البيانات.
  • Deauthentication Attack: استغلال إطارات إدارة غير مشفرة لفصل الأجهزة.

استكشاف أخطاء لاسلكية

  • القنوات المثلى بـ2.4GHz: 1, 6, 11 (غير متداخلة).
  • Sticky Clients (لا تنتقل لـAP أفضل) وFlapping Clients (تنتقل بكثرة).
منهجية استكشاف أخطاء لاسلكية: تحديد المتطلبات → مسح ميداني بـWi-Fi Analyzer → تحديد مدى الـAP → اختبار واقعي.

الوحدة 13 — مقارنة طرق الوصول عن بُعد

Comparing Remote Access Methods — WAN & Internet Connectivity · VPN Protocols · Remote Management

الشبكات الواسعة والاتصال بالإنترنت

  • T1 (1.544 Mbps، TDM) · DSL (حتى ~24 Mbps) · Cable (HFC).
  • FTTC (ألياف للرصيف) مقابل FTTP (ألياف حتى المبنى، أعلى سرعة).

بروتوكولات VPN

  • IPSec: Transport Mode (يشفّر الحمولة فقط) مقابل Tunnel Mode (يشفّر الحزمة كاملة).
  • IKEv2 يدعم EAP وNAT وMOBIKE، مفضّل عن IKEv1.
  • Client-to-Site VPN (عميل فردي) مقابل Site-to-Site VPN (اتصال دائم بين شبكتين).
  • Split Tunnel (ترافيك الشركة فقط) مقابل Full Tunnel (كل الترافيك).

الإدارة عن بُعد

  • SSH (مشفّر بالكامل) — يُفضَّل دائمًا على Telnet (TCP 23، غير مشفّر).
  • RDP (TCP 3389، مؤمّن بـNLA)؛ Jump Box: نقطة وصول إدارية وحيدة تقلل سطح الهجوم.
  • OOB Management: قناة إدارية معزولة عن ترافيك البيانات (مثل منفذ AUX).
Telnet = منفذ 23 وغير مشفّر (خطر أمني)، بينما SSH هو البديل الآمن الموصى به دائمًا.

الوحدة 14 — تلخيص مفاهيم السحابة

Summarizing Cloud Concepts — Datacenter & Storage Networks · Cloud Concepts · Cloud Networking · Modern Network Environments

شبكات مراكز البيانات والتخزين

  • North-South Traffic (عملاء خارجيون) مقابل East-West Traffic (بين السيرفرات).
  • Spine and Leaf Topology: كل leaf متصل بكل spine؛ latency بقفزة واحدة، يُلغي الحاجة لـSTP.
  • SAN: تخزين على مستوى الكتلة عبر Fibre Channel.

مفاهيم الحوسبة السحابية

  • Scalability (يدوي) مقابل Elasticity (تلقائي حسب الطلب).
  • نماذج الخدمة: IaaS (موارد افتراضية) · PaaS (أدوات تطوير) · SaaS (تطبيقات جاهزة).

الشبكات السحابية

  • VMs (عزل كامل) مقابل Containers (تشارك الـkernel، أخف).
  • VPC: Public Subnet تحتاج Internet Gateway، Private Subnet بدون مسار افتراضي للإنترنت.
  • Security Groups (instance، stateful) مقابل Security Lists (subnet، stateless).

بيئات الشبكات الحديثة

  • SDN: يفصل التحكم عن التوجيه — Southbound APIs (للأجهزة)، Northbound APIs (للتطبيقات).
  • Zero Trust: لا ثقة افتراضية + تحقق مستمر + أقل صلاحية ممكنة (microsegmentation).
SASE = دمج SD-WAN مع SSE (يشمل Zero Trust وCASB) في بنية سحابية موحدة للشبكة والأمان.
