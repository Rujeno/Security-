شبكات مراكز البيانات والتخزين

Summarizing Cloud Concepts — Datacenter and Storage Networks

مكونات تصميم شبكة مركز البيانات الحديث: Virtualization (شبكات رشيقة وقابلة للتوسع)، Overlay Networks (ترافيك آمن ومرن بين السيرفرات)، Zero Trust Architecture (مصادقة/تفويض لكل طلب)، وميزات High Availability (شبكة، طاقة، مناخ، تحكم بالوصول).

North-South Traffic

وصول العملاء الخارجيين لموارد مركز البيانات.

East-West Traffic

تواصل السيرفرات ببعضها داخل مركز البيانات — يحتاج أمانًا متقدمًا وإدارة ترافيك فعّالة.

Spine and Leaf Topology: هيكلية ثنائية الطبقة لتحسين تدفق ترافيك مركز البيانات.

  • Spine Layer: العمود الفقري بسويتشات توزيع عليا، متصلة بكل سويتشات الـleaf لكن ليس ببعضها.
  • Leaf Layer: سويتشات وصول متصلة بكل سويتش spine بهيكلية full mesh — مسارات مباشرة للأجهزة بدون اتصالات بين الـleaf switches نفسها.

فوائدها: latency متوقعة (قفزة واحدة من أي سيرفر للعمود الفقري)، موازنة حمل وfailover (مسارات متعددة زائدة)، تصميم بلا حلقات (يُلغي الحاجة لـSTP)، قابلية توسع وتكرار (إضافة عقد spine/leaf بسهولة)، واتصال عالي السرعة (سويتشات ToR).

كل leaf switch متصل بكل spine switch (full mesh) — أي سيرفر يصل لأي سيرفر آخر بقفزة واحدة فقط عبر العمود الفقري.

SAN (Storage Area Network): شبكة مخصصة لتوفير وصول لتخزين بيانات موحّد على مستوى الكتلة (block-level)، تفصل موارد التخزين عن الشبكة المحلية.

مكوناتها: أجهزة تخزين (RAID arrays، مكتبات أشرطة)، SAN Fabric (سويتشات وdirectors تربط السيرفرات بأجهزة التخزين)، وSAN Software (أدوات إدارة وإعداد).

فوائدها: توفر عالٍ، قابلية توسع، latency منخفض وthroughput عالٍ. حالات الاستخدام: إدارة قواعد البيانات، استمرارية الأعمال، والتخزين السحابي.

Fibre Channel (FC): بروتوكول نقل بيانات عالي السرعة، العمود الفقري لشبكات SAN (الإملاء البريطاني "Fibre" يميّزه عن كيابل الألياف البصرية "fiber"). المكونات: Initiators (سيرفرات بـHBA)، Targets (منافذ أجهزة التخزين)، وFC Switches. المزايا: أداء، مرونة، سرعة، وآليات QoS.

مفاهيم الحوسبة السحابية — Cloud Concepts

Scalability · Elasticity · Deployment Models · Service Models

Scalability (قابلية التوسع)

قدرة النظام السحابي على التعامل مع كمية عمل متزايدة. أنواعها: Horizontal Scaling (توسع أفقي — إضافة/إزالة سيرفرات) وVertical Scaling (توسع رأسي — ترقية مواصفات سيرفر موجود).

Elasticity (المرونة)

قدرة النظام على تعديل وتخصيص موارد الحوسبة تلقائيًا حسب الطلب — تضمن أداءً مثاليًا رغم تذبذب الاستخدام (توسع تلقائي، فعالية تكلفة، استجابة لحظية).

CDN (Content Delivery Network): حل تخزين مؤقت (caching) للمواقع/التطبيقات عالية الترافيك — يوزّع السيرفرات والملفات قرب المستخدم لوصول أسرع، عبر مراكز بيانات موزّعة جغرافيًا، يحسّن التوفر والأداء وقابلية التوسع، ويتعامل بسهولة مع ارتفاعات الترافيك المفاجئة.

الشبكات السحابية — Cloud Networking

Cloud Instances · VPCs · Gateways · Cloud Firewalls

نوع الـInstanceالوصف
Virtual Machines (VMs)سيرفرات كاملة بعتاد محاكى، تشغّل نظام تشغيل وتطبيقات متعددة — عزل كامل، استهلاك موارد أعلى
Containersبيئات معزولة خفيفة لتشغيل التطبيقات، تشارك kernel المضيف — استهلاك أقل، سهلة التوسع والإدارة

VPC (Virtual Private Cloud): بيئة معزولة داخل سحابة عامة، تتيح تشغيل التطبيقات بأمان.

  • كل VPC معزول عن باقي المستأجرين (tenants) بالسحابة.
  • المستأجرون يمكنهم تخصيص شبكتهم الافتراضية.
  • طبقات أمان متعددة، منها security groups وACLs.

Public Subnet: يتطلب ربط Internet Gateway وضبطه كمسار افتراضي. Private Subnet: تبقى خاصة بدون مسار افتراضي للإنترنت حتى لو مربوطة بـInternet Gateway.

بيئات الشبكات الحديثة — Modern Network Environments

IaC · SDN · Overlay Networks · Zero Trust · SASE

IaC (Infrastructure as Code): إدارة البنية التحتية عبر ملفات تعريف قابلة للقراءة آليًا — كود لإدارة وتوفير البنية التحتية تلقائيًا وبأمان، لنشر متسق وسريع وفعّال التكلفة.

أدوات IaC: Terraform (كود إعلاني لتوفير أي سحابة/بنية)، Ansible (لغة إعلانية للأتمتة)، Chef (recipes/cookbooks)، Puppet (نهج إعلاني)، AWS CloudFormation.

Source Control: طريقة لإدارة وتتبّع تغييرات الكود بتطوير البرمجيات — أساسي للمشاريع التعاونية وسلامة الكود. المكونات: version control، central repository، branching، وconflict identification.

SDN (Software-Defined Networking): يبسّط إدارة الشبكة بفصل وظائف التحكم والتوجيه، يسمح بالبرمجة المباشرة للتحكم بالشبكة.

  • SDN Controller: "دماغ" الشبكة.
  • Southbound APIs: التواصل بين الـcontroller والأجهزة.
  • Northbound APIs: الواجهة بين الـcontroller وتطبيقات الأعمال.

حالات استخدام: افتراضية الشبكة، الحوسبة السحابية، إدارة مراكز البيانات، وإنترنت الأشياء.

Overlay Network: شبكة افتراضية مبنية فوق شبكة فيزيائية موجودة، تتيح روابط منطقية بين العقد. أمثلة: VPNs، بروتوكولات تغليف مثل VXLAN (لتطبيقات مراكز البيانات) — تسهّل تقسيم الشبكة وعزلها.

SD-WAN: نهج مبتكر لتصميم WAN المؤسسات — اتصال محسّن بين الفروع ومراكز البيانات والسحابة، تحسين تدفق الترافيك بالأتمتة والإدارة المركزية وأنفاق IPsec آمنة.

Zero Trust Architecture — المبادئ الأساسية:

  • Assume No Trust: لا يُوثَق بأي جهة (مستخدم/جهاز) افتراضيًا، سواء داخل الشبكة أو خارجها.
  • Continuous Verification: مصادقة وتفويض مستمر لكل جلسة/معاملة.
  • Least Privilege Access: أقل صلاحيات ممكنة لإنجاز المهمة، لتقليل مسارات الهجوم المحتملة.

التطبيق: مصادقة/تفويض قائم على السياسة مركزيًا، فصل مستويات التحكم والبيانات، ومناطق ثقة ضمنية وتقسيم دقيق (microsegmentation).

SASE (Secure Access Service Edge): بنية سحابية تجمع وظائف الشبكة والأمان بانتشار عالمي — تدمج SD-WAN مع SSE (Secure Service Edge). وظائف SSE تشمل Zero Trust وCASB (Cloud Access Security Broker) الذي يفرض سياسات الأمان، يفحص البرمجيات الضارة، ويراقب النشاط — عبر Forward Proxy، Reverse Proxy، أو API.
