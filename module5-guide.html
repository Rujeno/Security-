تقنيات التوجيه — Routing Technologies

Configuring Routing and Advanced Switching — Routing Tables & Path Selection

إدخال جدول التوجيه (Routing Table Entry) يتحدد بأربع معلومات أساسية:

  • Protocol: البروتوكول المستخدم لتعلّم المسار (static, RIP, OSPF...).
  • Destination: الشبكة الوجهة.
  • Interface: المنفذ الخارج منه الترافيك.
  • Gateway/Next hop: العنوان التالي في الطريق للوصول للوجهة.

أنواع إدخالات جدول التوجيه: Directly connected routes (شبكات متصلة مباشرة) · Remote routes (شبكات بعيدة عبر راوتر آخر) · Host routes (مسار لمضيف واحد محدد) · Default route (المسار الافتراضي لأي وجهة غير معروفة).

Receive the packet←Examine the packet←Consult the routing table←Make a forwarding decision←Forward the packet

قاعدة وضع الراوتر (Router Placement):

  • الأجهزة على نفس الـsubnet/IP network لا يجب أن يفصل بينها راوتر.
  • الأجهزة على subnets/IP networks مختلفة يجب أن يفصل بينها راوتر.

بروتوكولات التوجيه الديناميكي — Dynamic Routing

Static vs Dynamic Routing · RIP · EIGRP · OSPF · BGP

الخاصيةStatic RoutingDynamic Routing
الإعداديدوييتكيّف تلقائيًا مع تغيّرات الشبكة
المرونةغير مرن — يحتاج تدخل يدوي للتحديثمرن — يتكيّف لحظيًا

بروتوكولات التوجيه الديناميكي (Dynamic Routing Protocols): خوارزميات تحدّث معلومات المسار تلقائيًا وتضبط المسارات بين عقد الشبكة عبر توزيع معلومات الـtopology.

المزايا: قابلية التوسع، التكيّف مع تغيّرات الشبكة، وتقليل عبء الإدارة.

اعتبارات: تحتاج معالجة وذاكرة أكبر، والإعداد الصحيح مهم جدًا للأمان والكفاءة.

RIP (Routing Information Protocol)

بروتوكول قديم (legacy) يجد أفضل مسار باستخدام hop count كمقياس، بحد أقصى 15 hop. غير مناسب للشبكات الكبيرة وبطيء التقارب (convergence).

EIGRP (Enhanced IGRP)

بروتوكول distance-vector متقدم، يستخدم مقاييس (bandwidth, delay, load, reliability)، يدعم IPv4 وIPv6 معًا. ملكية Cisco وأكثر تعقيدًا بالإعداد.

OSPF (Open Shortest Path First)

بروتوكول link-state يحسب أقصر مسار عبر خوارزمية Shortest Path First، يدعم topologies معقدة، لكنه يحتاج تخطيطًا أدق وbandwidth أكثر من بروتوكولات distance-vector.

BGP (Border Gateway Protocol)

بروتوكول يمكّن الإنترنت من تبادل معلومات التوجيه بين autonomous systems. قابل للتوسع لحجم الإنترنت، يستخدم path vector، ويدعم CIDR.

ترجمة عناوين الشبكة — Network Address Translation

NAT Types · Edge Routers · PAT

NAT: يعدّل معلومات عنوان الشبكة في رؤوس الحزم أثناء عبورها، ما يزيد الأمان بإخفاء عناوين IP الداخلية عن الشبكات الخارجية، ويتيح لعدة أجهزة بالشبكة المحلية مشاركة عنوان IP عام واحد، وبالتالي يوفّر عناوين IP العامة.

NAT يترجم عناوين IP الخاصة المتعددة داخل الشبكة المحلية إلى عنوان IP عام واحد عند الخروج للإنترنت.

Dynamic NAT

يربط العناوين الداخلية بمجموعة (pool) من العناوين الخارجية ديناميكيًا — يسمح لعدد أكبر من الأجهزة بمشاركة نفس عناوين IP الخارجية.

Static NAT

يترجم عنوان IP داخلي واحد إلى عنوان IP خارجي واحد ثابت — يسمح باتصالات واردة (inbound) تبدأ من خارج الشبكة.

Edge Router: يقع عند حدود الشبكة المتصلة بشبكات خارجية (كالإنترنت)، يدير تدفق البيانات بين الداخل والخارج، يوجّه البيانات لوجهتها، وينفّذ NAT ويطبّق إجراءات الأمان.

  • CE (Customer Edge): عند حافة شبكة العميل، يربط الشبكة الداخلية بشبكة المزوّد ويعمل كحاجز أمني.
  • PE (Provider's Edge): عند حافة شبكة المزوّد، يركّز على حماية سرية بيانات العميل أثناء عبورها شبكة المزوّد.
PAT (Port Address Translation): شكل من NAT يسمح لعدة أجهزة داخلية بمشاركة عنوان IP عام واحد في نفس الوقت، عبر تمييز كل اتصال برقم منفذ (port) مختلف — الأشيع استخدامًا في راوترات SOHO.

هيكليات شبكات المؤسسات — Enterprise Network Topologies

Tree Topology · Hybrid Topologies

Tree Topology: هيكلية هرمية تجمع خصائص من الـstar والـbus — عقد مجمّعة في مجموعات نجمية (star groups) متصلة ببعضها عبر backbone خطي.

Hybrid Topologies: تُستخدم عندما لا تكفي هيكلية أساسية واحدة (star/mesh/point-to-point)، فتُمزَج عدة هيكليات معًا لتحقيق التكرار (redundancy) وتحمّل الأعطال (fault tolerance).

  • Hierarchical Star: طبقات متتالية من الـstar topology.
  • Hierarchical Star-Mesh: دمج الـstar الهرمي مع روابط mesh للتكرار.
  • Star of Stars: مجموعات star متصلة بنقطة مركزية.
  • 3-Tiered Network Hierarchy: ثلاث طبقات (core, distribution, access) — الأشيع في شبكات المؤسسات الكبيرة.

الشبكات المحلية الافتراضية — Virtual LANs

VLAN Segmentation · Tagging · VLAN Types · Trunking

VLAN: تُنشئ شبكات منفصلة منطقيًا داخل بنية تحتية فيزيائية واحدة.

  • Segmentation: تقسّم الشبكة لأجزاء معزولة صغيرة، بدون الحاجة لعتاد منفصل.
  • Flexibility: تجميع المستخدمين والأجهزة حسب الوظيفة أو القسم أو الفريق، بغض النظر عن الموقع الفيزيائي.
  • Simplified Administration: يمكن إدارة تغييرات/نقل الشبكة بسهولة دون تعديل التمديدات الفيزيائية.

VLAN IDs والعضوية: كل VLAN له معرّف فريد (VLAN ID)، وكل جهاز عضو في VLAN معيّن. الأجهزة تستخدم VLAN IDs لإدارة الترافيك، ويحتاج Inter-VLAN routing للتواصل بين VLANs مختلفة.

نفس السويتش الفيزيائي، لكن كل مجموعة منافذ (ports) معزولة منطقيًا في VLAN مختلف — كأنها شبكات منفصلة تمامًا رغم مشاركة نفس العتاد.

Port Tagging: طريقة لتوسيم حزم البيانات بمعرّف VLAN.

  • Tagged ports: مُهيّأة لاستقبال وفهم الحزم التي تحمل معرّف VLAN.
  • Untagged ports: تستقبل البيانات بدون معرّف VLAN.
