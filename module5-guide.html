Routing Technologies

Configuring Routing and Advanced Switching — Routing Tables & Path Selection

إدخال جدول التوجيه (Routing Table Entry) يتحدد بأربع معلومات أساسية:

A Routing Table Entry is defined by four core pieces of information:

  • Protocol: البروتوكول المستخدم لتعلّم المسار (static, RIP, OSPF...).
  • Destination: الشبكة الوجهة.
  • Interface: المنفذ الخارج منه الترافيك.
  • Gateway/Next hop: العنوان التالي في الطريق للوصول للوجهة.
  • Protocol: the protocol used to learn the route (static, RIP, OSPF...).
  • Destination: the destination network.
  • Interface: the port the traffic exits from.
  • Gateway/Next hop: the next address on the way to the destination.

أنواع إدخالات جدول التوجيه: Directly connected routes (شبكات متصلة مباشرة) · Remote routes (شبكات بعيدة عبر راوتر آخر) · Host routes (مسار لمضيف واحد محدد) · Default route (المسار الافتراضي لأي وجهة غير معروفة).

Types of routing table entries: Directly connected routes (directly connected networks) · Remote routes (remote networks via another router) · Host routes (a route to one specific host) · Default route (the fallback route for any unknown destination).

Receive the packet←Examine the packet←Consult the routing table←Make a forwarding decision←Forward the packet

قاعدة وضع الراوتر (Router Placement):

The Router Placement rule:

  • الأجهزة على نفس الـsubnet/IP network لا يجب أن يفصل بينها راوتر.
  • الأجهزة على subnets/IP networks مختلفة يجب أن يفصل بينها راوتر.
  • Devices on the same subnet/IP network must not be separated by a router.
  • Devices on different subnets/IP networks must be separated by a router.

Dynamic Routing Protocols

Static vs Dynamic Routing · RIP · EIGRP · OSPF · BGP

بروتوكولات التوجيه الديناميكي (Dynamic Routing Protocols): خوارزميات تحدّث معلومات المسار تلقائيًا وتضبط المسارات بين عقد الشبكة عبر توزيع معلومات الـtopology.

Dynamic Routing Protocols: algorithms that automatically update route information and adjust paths between network nodes by distributing topology information.

المزايا: قابلية التوسع، التكيّف مع تغيّرات الشبكة، وتقليل عبء الإدارة.

Advantages: scalability, adapting to network changes, and reducing administrative overhead.

اعتبارات: تحتاج معالجة وذاكرة أكبر، والإعداد الصحيح مهم جدًا للأمان والكفاءة.

Considerations: needs more processing power and memory, and correct configuration is critical for security and efficiency.

RIP (Routing Information Protocol)

بروتوكول قديم (legacy) يجد أفضل مسار باستخدام hop count كمقياس، بحد أقصى 15 hop. غير مناسب للشبكات الكبيرة وبطيء التقارب (convergence).

A legacy protocol that finds the best path using hop count as its metric, with a maximum of 15 hops. Not suitable for large networks and slow to converge.

EIGRP (Enhanced IGRP)

بروتوكول distance-vector متقدم، يستخدم مقاييس (bandwidth, delay, load, reliability)، يدعم IPv4 وIPv6 معًا. ملكية Cisco وأكثر تعقيدًا بالإعداد.

An advanced distance-vector protocol, using metrics (bandwidth, delay, load, reliability), supporting both IPv4 and IPv6. Cisco-proprietary and more complex to configure.

OSPF (Open Shortest Path First)

بروتوكول link-state يحسب أقصر مسار عبر خوارزمية Shortest Path First، يدعم topologies معقدة، لكنه يحتاج تخطيطًا أدق وbandwidth أكثر من بروتوكولات distance-vector.

A link-state protocol that computes the shortest path using the Shortest Path First algorithm, supports complex topologies, but needs more careful planning and more bandwidth than distance-vector protocols.

BGP (Border Gateway Protocol)

بروتوكول يمكّن الإنترنت من تبادل معلومات التوجيه بين autonomous systems. قابل للتوسع لحجم الإنترنت، يستخدم path vector، ويدعم CIDR.

The protocol that lets the internet exchange routing information between autonomous systems. Scalable to the size of the internet, uses path vector, and supports CIDR.

ترجمة عناوين الشبكة — Network Address Translation

Network Address Translation

NAT Types · Edge Routers · PAT

NAT: يعدّل معلومات عنوان الشبكة في رؤوس الحزم أثناء عبورها، ما يزيد الأمان بإخفاء عناوين IP الداخلية عن الشبكات الخارجية، ويتيح لعدة أجهزة بالشبكة المحلية مشاركة عنوان IP عام واحد، وبالتالي يوفّر عناوين IP العامة.

NAT: modifies network address information in packet headers as they pass through, increasing security by hiding internal IP addresses from external networks, and letting several devices on the local network share a single public IP — thus conserving public IP addresses.

NAT يترجم عناوين IP الخاصة المتعددة داخل الشبكة المحلية إلى عنوان IP عام واحد عند الخروج للإنترنت.
NAT translates multiple private IP addresses inside the local network into a single public IP address when exiting to the internet.

Dynamic NAT

يربط العناوين الداخلية بمجموعة (pool) من العناوين الخارجية ديناميكيًا — يسمح لعدد أكبر من الأجهزة بمشاركة نفس عناوين IP الخارجية.

Maps internal addresses to a pool of external addresses dynamically — letting more devices share the same external IP addresses.

Static NAT

يترجم عنوان IP داخلي واحد إلى عنوان IP خارجي واحد ثابت — يسمح باتصالات واردة (inbound) تبدأ من خارج الشبكة.

Translates one internal IP address to one fixed external IP address — allowing inbound connections that originate from outside the network.

Edge Router: يقع عند حدود الشبكة المتصلة بشبكات خارجية (كالإنترنت)، يدير تدفق البيانات بين الداخل والخارج، يوجّه البيانات لوجهتها، وينفّذ NAT ويطبّق إجراءات الأمان.

Edge Router: sits at the boundary of a network connecting to external networks (like the internet), manages data flow between inside and outside, routes data to its destination, and performs NAT and applies security measures.

  • CE (Customer Edge): عند حافة شبكة العميل، يربط الشبكة الداخلية بشبكة المزوّد ويعمل كحاجز أمني.
  • PE (Provider's Edge): عند حافة شبكة المزوّد، يركّز على حماية سرية بيانات العميل أثناء عبورها شبكة المزوّد.
  • CE (Customer Edge): at the edge of the customer's network, connects the internal network to the provider's network and acts as a security boundary.
  • PE (Provider's Edge): at the edge of the provider's network, focused on protecting the confidentiality of customer data as it crosses the provider's network.
PAT (Port Address Translation): شكل من NAT يسمح لعدة أجهزة داخلية بمشاركة عنوان IP عام واحد في نفس الوقت، عبر تمييز كل اتصال برقم منفذ (port) مختلف — الأشيع استخدامًا في راوترات SOHO.
PAT (Port Address Translation): a form of NAT that lets several internal devices share a single public IP address at the same time, by distinguishing each connection with a different port number — the most common form used in SOHO routers.

هيكليات شبكات المؤسسات — Enterprise Network Topologies

Enterprise Network Topologies

Tree Topology · Hybrid Topologies

Tree Topology: هيكلية هرمية تجمع خصائص من الـstar والـbus — عقد مجمّعة في مجموعات نجمية (star groups) متصلة ببعضها عبر backbone خطي.

Tree Topology: a hierarchical structure combining traits of star and bus — nodes grouped into star groups connected to one another over a linear backbone.

Hybrid Topologies: تُستخدم عندما لا تكفي هيكلية أساسية واحدة (star/mesh/point-to-point)، فتُمزَج عدة هيكليات معًا لتحقيق التكرار (redundancy) وتحمّل الأعطال (fault tolerance).

Hybrid Topologies: used when a single basic topology (star/mesh/point-to-point) isn't enough, so several topologies are blended together to achieve redundancy and fault tolerance.

  • Hierarchical Star: طبقات متتالية من الـstar topology.
  • Hierarchical Star-Mesh: دمج الـstar الهرمي مع روابط mesh للتكرار.
  • Star of Stars: مجموعات star متصلة بنقطة مركزية.
  • 3-Tiered Network Hierarchy: ثلاث طبقات (core, distribution, access) — الأشيع في شبكات المؤسسات الكبيرة.
  • Hierarchical Star: successive layers of star topology.
  • Hierarchical Star-Mesh: combining a hierarchical star with mesh links for redundancy.
  • Star of Stars: star groups connected to a central point.
  • 3-Tiered Network Hierarchy: three layers (core, distribution, access) — the most common in large enterprise networks.

الشبكات المحلية الافتراضية — Virtual LANs

Virtual LANs

VLAN Segmentation · Tagging · VLAN Types · Trunking

VLAN: تُنشئ شبكات منفصلة منطقيًا داخل بنية تحتية فيزيائية واحدة.

VLAN: creates logically separate networks within a single physical infrastructure.

  • Segmentation: تقسّم الشبكة لأجزاء معزولة صغيرة، بدون الحاجة لعتاد منفصل.
  • Flexibility: تجميع المستخدمين والأجهزة حسب الوظيفة أو القسم أو الفريق، بغض النظر عن الموقع الفيزيائي.
  • Simplified Administration: يمكن إدارة تغييرات/نقل الشبكة بسهولة دون تعديل التمديدات الفيزيائية.
  • Segmentation: splits the network into small isolated parts, without needing separate hardware.
  • Flexibility: grouping users and devices by function, department, or team, regardless of physical location.
  • Simplified Administration: network changes/moves can be managed easily without touching the physical wiring.

VLAN IDs والعضوية: كل VLAN له معرّف فريد (VLAN ID)، وكل جهاز عضو في VLAN معيّن. الأجهزة تستخدم VLAN IDs لإدارة الترافيك، ويحتاج Inter-VLAN routing للتواصل بين VLANs مختلفة.

VLAN IDs and membership: every VLAN has a unique identifier (VLAN ID), and every device is a member of a specific VLAN. Devices use VLAN IDs to manage traffic, and Inter-VLAN routing is needed for different VLANs to communicate.

نفس السويتش الفيزيائي، لكن كل مجموعة منافذ (ports) معزولة منطقيًا في VLAN مختلف — كأنها شبكات منفصلة تمامًا رغم مشاركة نفس العتاد.
The same physical switch, but each group of ports is logically isolated into a different VLAN — as if they were completely separate networks despite sharing the same hardware.

Port Tagging: طريقة لتوسيم حزم البيانات بمعرّف VLAN.

Port Tagging: a way of marking data packets with a VLAN identifier.

  • Tagged ports: مُهيّأة لاستقبال وفهم الحزم التي تحمل معرّف VLAN.
  • Untagged ports: تستقبل البيانات بدون معرّف VLAN.
  • Tagged ports: configured to receive and understand packets carrying a VLAN identifier.
  • Untagged ports: receive data with no VLAN identifier.

Routing and VLAN Troubleshooting

Routing and VLAN Troubleshooting

مشاكل جدول التوجيه: اشتبهي بمشكلة توجيه إذا نجح ping للـdefault gateway لكن فشل مع بعض/كل المضيفين على شبكة بعيدة.

Routing table problems: suspect a routing problem if a ping to the default gateway succeeds but fails with some/all hosts on a remote network.

Verify connectivity←Review routing table entries←Check subnet masks←Examine static & dynamic routes←Use traceroute

مشاكل الـDefault Route وحلقات التوجيه: إعداد خاطئ لـdefault routes أو توزيعها لراوترات أخرى قد يسبب routing loops.

Default Route problems and routing loops: misconfigured default routes, or distributing them to other routers, can cause routing loops.

Verify host configuration←Ping default gateway←Check router settings←Review physical connections←Identify routing loops

مشاكل تخصيص VLAN: الأجهزة على نفس VLAN تحتاج إعداد IP متطابق (عنوان، subnet mask، gateway، DNS).

VLAN assignment problems: devices on the same VLAN need matching IP configuration (address, subnet mask, gateway, DNS).

Check physical connectivity←Ping the loopback address←Ping the default gateway←Ping a remote host or server
ملخص الوحدة 5: جداول التوجيه هي خرائط الراوتر الداخلية لتوجيه الحزم؛ التوجيه الديناميكي يُؤتمت تبادل معلومات المسار بين الراوترات؛ NAT يترجم بين عناوين خاصة وعامة للوصول للإنترنت؛ VLANs تنشئ أجزاء شبكة منطقية داخل شبكة فيزيائية واحدة.
Module 5 summary: routing tables are a router's internal map for forwarding packets; dynamic routing automates the exchange of route information between routers; NAT translates between private and public addresses for internet access; VLANs create logical network segments within a single physical network.
