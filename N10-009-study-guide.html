مفهوم الشبكة وأنواعها

Networking Overview — Network Types and Characteristics

الشبكة (Network): مجموعة من الأجهزة (computers and devices) متصلة ببعضها عبر transmission medium (وسيط نقل: كيبل نحاسي، ألياف بصرية، أو لاسلكي)، هدفها مشاركة الموارد (shared resources) والتواصل وتبادل المعلومات — تمامًا مثل شبكتك الاجتماعية لكن في بيئة رقمية.

نموذجا التشغيل: Peer-to-Peer vs Client-Server

Peer-to-Peer (P2P)

كل جهاز يعمل كـ client وserver في نفس الوقت. لا يوجد جهاز مركزي. مناسبة للشبكات الصغيرة، لكن إدارتها وأمانها أصعب مع التوسع.

Client-Server

يوجد server مركزي يقدّم الخدمات والموارد (ملفات، طباعة، مصادقة) لأجهزة الـclients. هذا هو النموذج المعتمد في بيئات الشركات — مثل بيئتك في مدائن مع Google Workspace.

الشبكة المحلية LAN وأنواعها

Local Area Network (LAN): شبكة محصورة في موقع جغرافي واحد (single geographical location). أنواعها حسب الحجم:

  • SOHO (Small Office / Home Office): شبكة منزل أو مكتب صغير، غالبًا راوتر واحد متعدد الوظائف.
  • Enterprise LAN: شبكة شركة بمبنى أو حرم، فيها سيرفرات وسويتشات مُدارة.
  • Datacenter: شبكة مخصصة لربط السيرفرات وأنظمة التخزين بكثافة عالية.
MODULE 1 · LESSON 1.1

هيكليات الشبكة — Network Topologies

الـTopology = مخطط الاتصالات بين أجهزة الشبكة (layout of connections)

1) Point-to-Point: عقدتان فقط (two nodes) متصلتان مباشرة بنفس الوسيط. مفاهيم مهمة هنا:

  • Half-duplex: الجهاز لا يستطيع الإرسال والاستقبال في نفس اللحظة (بالتناوب).
  • Full-duplex: إرسال واستقبال متزامن (simultaneously).

2) Star Topology: كل عقدة تتصل بجهاز مركزي يسمى concentrator عبر وسيط مخصص لها.

  • لو كان الـconcentrator يكرر الإشارة للجميع = يعمل كـEthernet hub (logical bus).
  • الأشيع: يتتبع عناوين الأجهزة ويوجّه الاتصال بشكل انتقائي = Switch (ينشئ point-to-point links).
  • العيب الأهم للاختبار: الـconcentrator هو single point of failure، وكل عقدة يجب أن تكون ضمن مسافة النقل القصوى للوسيط أو تستخدم repeater.

3) Mesh Topology:

  • Full mesh: كل عقدة متصلة بكل عقدة أخرى. عدد الروابط = n*(n−1)/2 — يكبر بسرعة مع إضافة العقد.
  • Partial mesh: الأكثر عملية؛ العقد تتعلم الـtopology وتمرر الحزم (forward packets).
  • الميزة: مسارات متعددة = مرونة عالية (resilience) عند فشل روابط أو عقد.
إذا شفتِ في السؤال "single point of failure" فكري بـStar، وإذا "redundant paths / resilience" فكري بـMesh، وإذا "two nodes only / duplex" فهي Point-to-Point.

نموذج OSI — الطبقات السبع

OSI Model Concepts — أهم موضوع تأسيسي في الشهادة كلها

نموذج مرجعي يقسّم عملية الاتصال الشبكي إلى 7 طبقات. عند المرسل (Sender) تنزل البيانات من الطبقة 7 إلى 1 (encapsulation)، وعند المستقبل (Receiver) تصعد من 1 إلى 7 (de-encapsulation).

الجملة التذكيرية (Mnemonic) من الطبقة 1 إلى 7: Please Do Not Throw Sausage Pizza Away

7
Application
تتفاعل مباشرة مع برامج المستخدم لطلب خدمة الشبكة. أمثلة: SMTP, DNS, FTP
6
Presentation
تجهيز شكل البيانات: Encryption/Decryption, Encoding, Compression, MIME
5
Session
إنشاء وإدارة الجلسات بين التطبيقات. أمثلة: NetBIOS, PAP, ASP, ADSP
4
Transport
تتبع الاتصال بين التطبيقات عبر الـports، تقسيم البيانات (segmentation) وإعادة تجميعها (reassembly). أجهزة: Multilayer switch, Advanced firewall, IDS
3
Network
نقل الحزم (packets) بين الشبكات باستخدام IP addresses. أجهزة: Router, ACL, Basic firewall
2
Data Link
نقل الـframes بين العقد على نفس الـsegment باستخدام MAC addresses. أجهزة: Switch, Bridge, NIC, Wireless AP
1
Physical
إرسال الـbits كإشارات عبر الوسيط. أمثلة: Cables, Hubs, Repeaters, Modem, Transceiver

تقسيم المسؤولية (يجي كثير بالاختبار):

  • الطبقات 1–3 (Physical, Data Link, Network) = Responsibility of the Network.
  • الطبقات 4–7 (Transport → Application) = Responsibility of the Host.
اربطي كل طبقة بوحدة بياناتها: L1 = Bits · L2 = Frames · L3 = Packets · L4 = Segments. واربطي الجهاز بالطبقة: Hub→1، Switch→2، Router→3.

SOHO Router — راوتر واحد بكل الطبقات

جهاز واحد يجمع وظائف عدة طبقات من OSI

الطبقةوظيفة الـSOHO Router فيها
Physical (L1)منافذ RJ-45 LAN ports لتوصيل الأجهزة سلكيًا، radio antennas للواي فاي، ومنفذ WAN port للاتصال بمزود الخدمة (ISP).
Data Link (L2)يعمل كـEthernet switch + Wireless Access Point (الـAP موصول داخليًا بمنفذ switch). كل جهاز يُعرَّف بـMAC address، والأجهزة السلكية واللاسلكية كلها على نفس layer 2 local network.
Network (L3)يوجّه بين الشبكة الخاصة المحلية والإنترنت العام، يشغّل DHCP server لتوزيع IP على الأجهزة، وواجهة الـWAN تأخذ public IP address.
Transport / Application (L4–L7)تقسيم البيانات (segmentation) وإعادة تجميعها، وتمرير طلبات واستجابات Application layer.

اتصال SOHO بالإنترنت: الـWAN يربط شبكتك بمزود الخدمة عبر بنية مثل PSTN (Public Switched Telephone Network)، والإنترنت نفسه يتكون من high-bandwidth trunks تربط نقاط تبادل الإنترنت IXPs (Internet Exchange Points) حيث تتصل شبكات مزودي الخدمة ببعض.

الأرقام الثنائية — Binary

أساس فهم IP addressing و Subnetting لاحقًا

النظام العشري (Base 10) خاناته: آحاد، عشرات، مئات... أما الثنائي (Binary / Base 2) فكل خانة من الـ8 bits لها وزن:

1286432168421
كل bit إما 1 (نجمع وزنه) أو 0 (نتجاهله)

مثال 1 — تحويل 205: نبدأ من الأكبر: 128 ✓ (باقي 77) → 64 ✓ (باقي 13) → 32 ✗ → 16 ✗ → 8 ✓ (باقي 5) → 4 ✓ (باقي 1) → 2 ✗ → 1 ✓
النتيجة: 205 = 1100 1101

مثال 2 — تحويل 132: 128 ✓ (باقي 4) → 4 ✓
النتيجة: 132 = 1000 0100

منهجية استكشاف الأخطاء — Troubleshooting Methodology

7 خطوات بالترتيب — احفظيها كتسلسل، الاختبار يسأل عن "الخطوة التالية"

1. Identify the problem← 2. Establish a theory of probable cause← 3. Test the theory← 4. Establish a plan of action← 5. Implement the solution← 6. Verify the solution← 7. Document findings, actions, and outcomes

الخطوة 1 — Identify the problem:

  • جمع المعلومات: system documentation, installation/maintenance logs, vendor support sites.
  • سؤال المستخدمين: open questions (لاكتشاف معلومات) وclosed questions (إجابة نعم/لا محددة).
  • تحديد الأعراض: فحص فعلي، سجلات (logs)، محاولة تكرار المشكلة (duplicate the problem).
  • هل تغيّر شيء؟ Did it ever work? What has changed since it was last working?
  • التعامل مع كل مشكلة على حدة (approach problems individually).

الخطوة 2 — Establish a theory: شكّكي في الأمور البديهية (question the obvious)، وأثبتي عمل كل مكوّن منهجيًا. باستخدام OSI:

  • Top-down: من Application نزولًا لـPhysical.
  • Bottom-up: من Physical صعودًا (الأشيع: تحقّقي من الكيبل أولًا!).
  • وأيضًا divide-and-conquer كاستراتيجية ثالثة.

الخطوة 3 — Test the theory: لا تقفزي للاستنتاجات. ومتى نصعّد (Escalation)؟

  • المشكلة تتجاوز معرفتك أو صلاحيتك.
  • الجهاز تحت system warranty.
  • نطاق المشكلة كبير جدًا، أو العميل صعب/مسيء.

الخطوات 5–7: نفّذي الحل (وصعّدي إذا احتجتِ صلاحية أعلى)، تحققي أن النظام يعمل لك وللمستخدم، ثم وثّقي — السجلات مفيدة لأي مشكلة مستقبلية.

Ethernet ومصطلحات نقل البيانات

Supporting Cabling and Physical Installations

مصطلحات أساسية:

  • Data transmission: نقل البيانات من جهاز لآخر عبر قنوات (channels) سلكية أو لاسلكية.
  • Digital signals: إشارات 1 و 0 تُنقل عبر القنوات.
  • Transmission media: نحاس (copper)، ألياف بصرية (fiber optic)، أو لاسلكي.
  • Data transfer rate: سرعة إرسال البيانات.
  • Error detection/correction: آليات كشف أخطاء النقل وتصحيحها.

CSMA/CD — تنظيم الوسيط المشترك

Carrier Sense Multiple Access with Collision Detection: بروتوكول ينظّم الاتصال في الشبكات ذات الوسيط المشترك (shared transmission medium).

Data to transmit←Check network (Carrier Sense)←Transmit←Collision?←Jam signal + Wait (Backoff)←Retransmit
  • Carrier Sense: الجهاز يستمع للوسيط قبل الإرسال.
  • Multiple Access: عدة أجهزة تشارك نفس الوسيط.
  • Collision Detection: لو أرسل جهازان معًا يُكتشف التصادم.
  • Resolution: إشارة Jam signal ثم انتظار عشوائي عبر Backoff algorithm قبل إعادة الإرسال.

الكيابل النحاسية والموصلات

Copper Cables and Connectors

UTP — Unshielded Twisted Pair

  • من 2 إلى 1800 زوج داخل غلاف بلاستيكي.
  • حماية ضعيفة من التداخل الكهرومغناطيسي (minimal EMI protection).
  • الأكثر شيوعًا في الـLANs لأنه اقتصادي.
  • فئات: Cat5e (1 Gbps) و Cat6a (10 Gbps).
  • التركيب: تجنّب الانحناءات الحادة والابتعاد عن مصادر EMI.

STP — Shielded Twisted Pair

  • أزواج نحاسية مجدولة + تدريع موصل (conductive shielding).
  • حماية من EMI وتقليل crosstalk.
  • الاستخدام: المناطق عالية التداخل (مصانع، آلات) ونقل البيانات الحساسة.
  • فئات: Cat5e, 6, 7 — ويحتاج تعامل حذر عند التركيب.

تصنيف مقاومة الحريق: Plenum vs Riser

Plenum-rated

  • يُركّب في فراغات تدوير الهواء (plenum spaces) فوق الأسقف المستعارة.
  • مواد مقاومة للحريق ومنخفضة السمّية، معايير سلامة أعلى، وأغلى.

Riser-rated

  • للفراغات الرأسية بين الطوابق.
  • مقاوم للحريق ويمنع انتشاره بين الأدوار، وأوفر تكلفة.

تنفيذ التمديدات — Structured Cabling

Wiring Implementation

Structured Cabling System: طريقة قياسية لتمديد الشبكات في المباني المكتبية، عناصرها:

  • Work Area: نقطة اتصال المستخدم.
  • Horizontal Cabling: التمديد الأفقي على مستوى الطابق (يربط الـwork areas بغرفة الاتصالات).
  • Telecommunications Room / Closet (IDF): غرفة/خزانة المعدات لكل طابق.
  • Backbone Cabling: التمديد الرأسي الذي يربط الطوابق وغرف المعدات.
  • Entrance Facilities / Demarc: نقطة دخول خدمة المزوّد وحدّ المسؤولية بينك وبين شركة الاتصالات (LEC).

معايير الإنهاء T568A / T568B: ترتيبان قياسيان لتوصيل الأزواج الأربعة (8 pins) في موصل RJ-45. الفرق بينهما تبديل مواقع الزوجين الأخضر والبرتقالي. المهم: استخدمي نفس المعيار على الطرفين للكيبل المستقيم (straight-through).

Patch Panels: لوحات تسهّل إدارة الكيابل — من الخلف punch down blocks (IDC terminals) لإنهاء الكيابل بشكل آمن ومضغوط، ومن الأمام منافذ RJ45 تتيح إعادة تشكيل التوصيلات بسهولة. تدعم T568A وT568B.

خطوات التركيب: Preparation (أدوات + مسار) → Pulling cable (ترقيم/تمرير/تحزيم) → Termination (اتركي service loop، قصّي ورقّمي) → Connection (patch panel + work area) → Testing → Documentation.

الألياف البصرية — Fiber Optic

Fiber Optic Cables and Connectors

التكوين: خيوط رفيعة من الزجاج أو البلاستيك تنقل البيانات بنبضات ضوئية:

  • Core: قلب زجاجي فائق النقاء يمر فيه الضوء.

المزايا: سرعات حتى 800 Gbps، جودة إشارة لمسافات طويلة، ومناعة كاملة ضد EMI.

WDM — Wavelength Division Multiplexing: تمرير عدة قنوات بيانات على نفس الليف باستخدام أطوال موجية مختلفة من الضوء:

  • BiDi (Bidirectional WDM): إرسال واستقبال على نفس الشعيرة بأطوال موجية مزاحة (Tx بـ1310nm / Rx بـ1490nm)، ويُركّب بأزواج متعاكسة. معايير: 1000BASE-BX, 10GBASE-BX.
  • CWDM (Coarse): حتى 16 طول موجي — عادة 4–8 قنوات ثنائية الاتجاه.
  • DWDM (Dense): قنوات أكثر بكثير (20 / 40 / 80 / 160)، يتطلب ليزرات دقيقة لأن التباعد بين القنوات أضيق.

عوامل التركيب الفيزيائي

Physical Installation Factors — server rooms & datacenters

Rack Systems: أنظمة رفوف فولاذية للمعدات القياسية داخل مناطق آمنة (غرف السيرفرات، خزائن الاتصالات) مع physical access control. المقاس القياسي EIA 19" / 48.26 cm.

الحرارة والرطوبة:

  • Temperature monitoring: منع ارتفاع الحرارة وضمان تبديد فعّال.
  • Humidity control: رطوبة عالية = تكاثف وتآكل (condensation & corrosion)، رطوبة منخفضة = شحنات ستاتيكية (static charge).
  • Flood detection: كشف مخاطر المياه وإيقاف الأنظمة فورًا.

إدارة الطاقة:

  • PDU (Power Distribution Unit): توزيع طاقة نظيفة + مراقبة وتحكم عن بُعد.
  • UPS (Uninterruptible Power Supply): استمرارية الطاقة عند الانقطاع (brownouts/blackouts)، ومدة تشغيله تعتمد على الحمل والموديل.
  • حماية من spikes, surges, failures.

إخماد الحريق — Fire Suppression:

  • Class C extinguishers للحرائق الكهربائية.
  • Sprinklers مائية = خطر انفجار أنابيب وتفعيل عرضي، لذا البدائل: Dry-pipe، Pre-action، Clean agent (غازات نظيفة)، وHalon (أُلغي تدريجيًا — phased out).
MODULE 2 · LESSON 2.6

استكشاف أخطاء الكيابل

Cable Troubleshooting — أهم درس عملي في الوحدة

مصطلحات القياس:

  • Speed (baud rate): عدد الرموز المرسلة في الـPhysical layer (Hz)، بينما bit rate / bandwidth بالـbps في Data Link.
  • Throughput: متوسط معدل النقل الفعلي عبر الزمن — يتأثر بالترميز والأخطاء والمسافة والتداخل.
  • Goodput: الإنتاجية على مستوى الـApplication layer بعد حساب فقد الحزم (packet loss).
  • Latency: زمن وصول الحزمة، يُقاس بـmilliseconds (ms).
  • Distance limitations: نوع الوسيط يحدد المسافة؛ الأداء يتأثر بالتوهين (attenuation, dB loss) والتداخل (SNR).

أعراض مشاكل الكيابل: بطء الإنترنت، انقطاعات عشوائية، connection timeouts، بطء التطبيقات، تقطيع الصوت/الفيديو، وعدم استقرار الرابط.

خطوات الفحص: فحص فيزيائي → التحقق من الـpatch cords واستبدالها بأخرى سليمة معروفة (known good) → اختبار الـtransceivers بأداة loopback → تجربة منفذ switch أو جهاز بديل → فحص التمديدات المهيكلة بالأدوات → التحقق من الـdrivers والـnetwork adapter.

Attenuation (التوهين): فقدان قوة الإشارة (يُقاس بـdB).

أسبابه: طول الكيبل، رفع الـimpedance، سلك رفيع، عوامل بيئية.
الحلول: تقصير المسافات، repeaters/extenders، كيابل أعلى جودة، وقياس التوهين عند التركيب.

Interference (التداخل): تأثير سلبي من إشارات EMI / RFI وcrosstalk وموصلات معيبة.

الحلول: التدريع (foil/braided shields)، تنظيم مسارات الكيابل، مواد متينة وstrain relief، واختبار التوافق.

أنواع الـCrosstalk (تداخل الإشارات بين الأزواج):

  • NEXT (Near End Crosstalk): عند طرف المرسل — سببه فك الجدل الزائد أو درع معيب.
  • ACRN (Attenuation to Crosstalk Ratio, Near end): مقارنة insertion loss مع NEXT — قيمة عالية = إشارة قوية.
  • ACRF (…, Far End): قياس FEXT عند طرف المستقبل — مستقل عن طول الرابط.
  • Power Sum: لكيابل Gigabit / 10GbE — يتأكد أن الكيبل مناسب للإرسال على كل الأزواج معًا.
  • Alien Crosstalk: تداخل من كيابل مجاورة بسبب التحزيم الضيق أو الإنهاء السيئ.

حلول الـcrosstalk: فحص التلف والتركيب الخاطئ، تجنّب فك الجدل الزائد (excessive untwisting)، تحزيم صحيح، وموصلات/كيابل مناسبة.

فرّقي: مشكلة عند نهاية المرسل = NEXT · عند المستقبل = ACRF/FEXT · من كيابل مجاورة = Alien Crosstalk · فقدان قوة الإشارة مع المسافة = Attenuation.

Configuring Interfaces and Switches — NIC, Transceivers, MAC & Ethernet Frame

NIC (Network Interface Card): مكوّن transceiver يربط المضيف بوسيط النقل (سلكي أو لاسلكي).

  • قد يحتوي على أكثر من منفذ على نفس البطاقة.
  • له عنوان MAC فريد.

  • انقطاع اتصال متقطع

مشاكل Signal Strength

  • اتصالات متقطعة
  • فقدان حزم (packet loss)
  • أداء شبكة ضعيف

سويتشات الإيثرنت — Ethernet Switches

Hub vs Bridge vs Switch وأنواع السويتشات

Hub

يعمل في Physical layer فقط. يرسل أي إشارة واردة إلى كل المنافذ الأخرى بدون أي ذكاء بالتوجيه.

Bridge

يفصل الشبكة إلى physical segments، لكنه يُبقي كل العُقد ضمن نفس الشبكة المنطقية.

Switch: يتعلم عناوين MAC ويرسل الإطار من منفذ واحد فقط لمنفذ الوجهة المحدد فقط — يقلل الازدحام ويحسّن الكفاءة، عكس الـHub الذي يبث للجميع.

أنواع سويتشات الإيثرنت

الإدارةManaged: يمكن إعداده وتخصيصهUnmanaged: لا خيارات إعداد
المنافذModular: أعداد/أنواع منافذ مختلفة قابلة للتهيئةFixed: عدد منافذ ثابت
التركيبDesktop: قائم بذاته (free standing)Rack-mounted: مصمم لخزائن الشبكات

لخّصيها: Hub = يبث للجميع (L1) · Bridge = يفصل segments لكن نفس الشبكة المنطقية · Switch = يوجّه بذكاء حسب MAC (L2) لمنفذ الوجهة فقط.

إعداد منافذ السويتش — Switch Port Configuration

Link Aggregation · MTU · STP · PoE

Link Aggregation / NIC Teaming

دمج رابطين أو أكثر من الكيبلات المنفصلة في قناة منطقية واحدة → توفر redundancy وهي cost effective.

MTU — Maximum Transmission Unit

الإطار العادي: 1500 bytes. الـJumbo frame: يدعم حمولة حتى 9216 bytes لتقليل عدد الإطارات، لكنه محدود لأنه يخالف معايير الإيثرنت القياسية.

Spanning Tree Protocol (STP)

بروتوكول Layer 2. يمنع bridge loops ويوفر fault tolerance.

Power over Ethernet (PoE)

يسمح لكيبل واحد بنقل البيانات والطاقة معًا للأجهزة المتصلة، ما يبسّط تركيب الشبكة وتوسعتها.

عنونة IPv4 — IPv4 Addressing

تركيب العنوان · Network/Host ID · Subnet Mask · Default Gateway

تركيب عنوان IPv4: تمثيل عشري لأربع مجموعات ثنائية (octets)، كل octet 8 bits → المجموع 32 bit.

مثال تحويل ثنائي: 11000011 → بالأوزان 128-64-32-16-8-4-2-1: البتات المفعّلة 64+32+1 = 97

تشبيه العمارة السكنية:

  • Network ID = رقم المبنى (مشترك بين كل السكان/المضيفين).
  • Host ID = رقم الشقة (يحدد مضيفًا بعينه داخل الشبكة).
  • Default Gateway = المدخل الرئيسي للمبنى — طريق الخروج للخارج (خارج الشبكة المحلية).
  • Broadcast Address = مثل مكبّر صوت يصل لكل السكان.

Subnet Mask: يحدد الجزء الخاص بالشبكة من عنوان IP. إذا طابق network ID الشبكةَ المحلية تُرسل الحزمة مباشرة، وإلا تُمرَّر (forwarded) لشبكة أخرى.

مثال: شبكة 192.168.1.x بقناع 255.255.255.0 → أول 3 octets (24 bit) للشبكة، والoctet الأخير للمضيف.

المدى 224.0.0.0–239.255.255.255 (المعروف بـClass D) قد يظهر بجانب الجدول أعلاه في بعض المراجع، لكنه فعليًا نطاق Multicast محجوز وليس عنونة خاصة عادية — لا تخلطي بينهما بالاختبار.

قواعد تصميم مخطط عنونة IPv4:

  • عدد الشبكات/الشبكات الفرعية المطلوبة، وعدد المضيفين بكل subnet.
  • الـNetwork ID يجب أن يكون من مدى خاص صالح.
  • لا يجوز أن يكون Network ID أو Host ID كله بتات 1 (فهذا عنوان broadcast).
  • كل Host ID فريد داخل الـsubnet، وكل Network ID فريد على مستوى الشبكة.

Classless Addressing (استعارة البتات / Borrowing Bits): استعارة بتات من جزء الـHost لصالح جزء الـNetwork → يزيد عدد الشبكات الفرعية المتاحة لكن يقلل عدد المضيفين الممكنين بكل subnet.

مثال: الشبكة 192.168.89.0/24 (قناع 255.255.255.0) — باستعارة بت واحد فقط:

  • الـNetwork ID الجديد: 192.168.89.128
  • مدى العناوين: 192.168.89.1 – 192.168.89.126
  • القناع الجديد: 255.255.255.128 أو /25

وباستعارة بتين: Network ID = 192.168.89.192، المدى 192.168.89.1–.62، القناع 255.255.255.192 (/26).

CIDR — Classless Inter-Domain Routing

يخصص مساحة عناوين IP بكفاءة أكبر، عبر دمج العنوان مع لاحقة (suffix) تمثّل جزء الشبكة، ويدعم variable-length subnetting.

VLSM — Variable Length Subnetting

ينشئ subnets بأحجام مختلفة داخل نفس الشبكة لتخصيص أكفأ لعناوين IP، لكنه يتطلب تخطيطًا وإدارة دقيقة.
