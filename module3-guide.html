واجهات الشبكة — Network Interfaces

Network Interfaces

Configuring Interfaces and Switches — NIC, Transceivers, MAC & Ethernet Frame

NIC (Network Interface Card): مكوّن transceiver يربط المضيف بوسيط النقل (سلكي أو لاسلكي).

NIC (Network Interface Card): a transceiver component that connects the host to the transmission medium (wired or wireless).

  • قد يحتوي على أكثر من منفذ على نفس البطاقة.
  • له عنوان MAC فريد.
  • يعمل في طبقة Data Link (L2).
  • May have more than one port on the same card.
  • Has a unique MAC address.
  • Operates at the Data Link (L2) layer.

أعراض مشاكل NIC: فشل اتصال الشبكة، بطء السرعة، اتصال متقطع، رسائل خطأ في Device Manager، رسائل خطأ بإعدادات الشبكة.

Symptoms of NIC problems: network connection failure, slow speed, intermittent connectivity, error messages in Device Manager, network configuration error messages.

Modular Transceivers: تُنهي أنواعًا متعددة من الكيابل والموصلات، وتعمل أيضًا في Data Link layer.

Modular Transceivers: terminate multiple cable and connector types, and also operate at the Data Link layer.

  • OUI (Organizationally Unique Identifier): يحدد الشركة المصنّعة.
  • Device ID: بناءً على موديل الجهاز وتاريخ التصنيع.

The Broadcast address: when a MAC address is all 1 bits (shown as FF:FF:FF:FF:FF:FF), every device on the network receives and processes the frame.

سويتشات الإيثرنت — Ethernet Switches

Ethernet Switches

Hub vs Bridge vs Switch وأنواع السويتشات

Hub vs Bridge vs Switch and switch types

Hub — Broadcast to All Ports
Bridge — Splits Physical Segments
Switch — Unicast to Destination Port

Hub

يعمل في Physical layer فقط. يرسل أي إشارة واردة إلى كل المنافذ الأخرى بدون أي ذكاء بالتوجيه.

Operates only at the Physical layer. Sends any incoming signal to every other port with no forwarding intelligence at all.

Bridge

يفصل الشبكة إلى physical segments، لكنه يُبقي كل العُقد ضمن نفس الشبكة المنطقية.

Splits the network into physical segments, but keeps all nodes within the same logical network.

Switch: يتعلم عناوين MAC ويرسل الإطار من منفذ واحد فقط لمنفذ الوجهة المحدد فقط — يقلل الازدحام ويحسّن الكفاءة، عكس الـHub الذي يبث للجميع.

Switch: learns MAC addresses and sends the frame out of only the specific destination port — reducing congestion and improving efficiency, unlike a Hub which broadcasts to everyone.

Sum it up: Hub = broadcasts to everyone (L1) · Bridge = splits segments but keeps the same logical network · Switch = intelligently forwards by MAC (L2) to the destination port only.

إعداد منافذ السويتش — Switch Port Configuration

Switch Port Configuration

Link Aggregation · MTU · STP · PoE

Link Aggregation / NIC Teaming

دمج رابطين أو أكثر من الكيبلات المنفصلة في قناة منطقية واحدة → توفر redundancy وهي cost effective.

Combining two or more separate cable links into a single logical channel → provides redundancy and is cost effective.

MTU — Maximum Transmission Unit

الإطار العادي: 1500 bytes. الـJumbo frame: يدعم حمولة حتى 9216 bytes لتقليل عدد الإطارات، لكنه محدود لأنه يخالف معايير الإيثرنت القياسية.

A normal frame: 1500 bytes. A Jumbo frame: supports a payload of up to 9216 bytes to reduce the number of frames, but its use is limited because it violates standard Ethernet specifications.

Spanning Tree Protocol (STP)

بروتوكول Layer 2. يمنع bridge loops ويوفر fault tolerance.

A Layer 2 protocol. Prevents bridge loops and provides fault tolerance.

Power over Ethernet (PoE)

يسمح لكيبل واحد بنقل البيانات والطاقة معًا للأجهزة المتصلة، ما يبسّط تركيب الشبكة وتوسعتها.

Allows a single cable to carry both data and power to connected devices, simplifying network installation and expansion.

حالات المنفذ (Interface Status):

Interface Status:

  • Down/down: الطبقتان Physical وData Link غير نشطتين.
  • Administratively down/down: تعطيل يدوي من المسؤول بأمر shutdown.
  • Down/error disabled: تعطيل تلقائي بسبب خطأ شبكة أو مخالفة سياسة.
  • Up/down (suspended): الطبقة الفيزيائية تعمل لكن Data Link معطلة (إعدادات إدارية أو أخطاء).
  • Down/down: both the Physical and Data Link layers are inactive.
  • Administratively down/down: manually disabled by the admin with the shutdown command.
  • Down/error disabled: automatically disabled due to a network error or policy violation.
  • Up/down (suspended): the Physical layer is up but Data Link is disabled (admin settings or errors).

عدادات أخطاء الواجهة (Interface Error Counters): Link state (حالة اتصال فورية) · Resets (عدد إعادة التشغيل اليدوية/التلقائية) · Discards/drops (أسبابها: أخطاء checksum، تعارض MTU، أحجام غير طبيعية، حمل عالٍ، أخطاء إعداد ACL/VLAN).

Interface Error Counters: Link state (real-time connection status) · Resets (number of manual/automatic restarts) · Discards/drops (causes: checksum errors, MTU mismatch, abnormal sizes, high load, ACL/VLAN configuration errors).

Network Loops

الأسباب: اتصالات زائدة، طرف الجهاز النهائي.
الحلول: تهيئة صحيحة للاتصالات الزائدة، تفعيل STP، توعية المستخدمين.

Causes: redundant connections, end-device wiring.
Solutions: proper configuration of redundant links, enabling STP, user awareness.

Broadcast Storms

الأسباب: مشاكل DHCP، نطاقات بث كبيرة جدًا.
الحلول: مراقبة حركة DHCP، تقسيم (segment) الشبكة.

Causes: DHCP problems, broadcast domains that are too large.
Solutions: monitoring DHCP traffic, segmenting the network.

مشاكل PoE:

PoE Problems:

  • الكيابل: يُفضَّل Cat5e فأعلى (يُنصح بـCat6A)؛ سماكة الموصل 23AWG أفضل من 24AWG؛ التدريع يساعد بتبديد الحرارة.
  • توافق المعيار: الأجهزة يجب أن تتفاوض على وضع PoE الصحيح (Alternative A أو B أو Four-pair).
  • إدارة ميزانية الطاقة: للسويتشات ميزانية طاقة محدودة (300–400W). استخدمي أمر show power inline للمراقبة.
  • Cabling: Cat5e or higher is preferred (Cat6A recommended); 23AWG conductor gauge is better than 24AWG; shielding helps dissipate heat.
  • Standard compatibility: devices must negotiate the correct PoE mode (Alternative A or B, or Four-pair).
  • Power budget management: switches have a limited power budget (300–400W). Use show power inline to monitor it.
ملخص الوحدة 3: NIC يربط المضيف بالشبكة وله MAC فريد؛ Transceiver يهيئ أنواع الكيابل؛ Hub يبث للجميع، Switch يوجّه بذكاء، Bridge يفصل الـsegments مع إبقاء الشبكة المنطقية موحدة؛ STP يمنع الحلقات ويوفر التحمل ضد الأعطال (L2).
Module 3 summary: a NIC connects the host to the network and has a unique MAC; a Transceiver adapts different cable types; a Hub broadcasts to everyone, a Switch forwards intelligently, a Bridge splits segments while keeping the logical network unified; STP prevents loops and provides fault tolerance (L2).
