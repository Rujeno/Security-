السياسات التنظيمية والتوثيق

Supporting Network Management — Organizational Policies and Documentation

أهمية التوثيق: يسهّل استكشاف الأخطاء، يضمن الاتساق، يدعم التوسع والترقيات، ويدعم استمرارية العمل عند تغيّر الموظفين.

أنواع التوثيق: Configuration management, Backup management, Change management, Asset management, Network management.

إدارة الإعدادات (Configuration Management):

Identify service assets←Consider a CMS solution←Determine an identification strategy←Establish a CI management plan←Monitor configuration drift

إدارة النسخ الاحتياطي لأجهزة الشبكة: توثيق النسخ الاحتياطية والإجراءات، جدول نسخ منتظم، تدقيق والتحقق من النسخ، الحفاظ على سجل الإصدارات، وضبط تسجيل بيانات الحالة عن بُعد.

إدارة التغيير (Change Management): بروتوكول توثيق شامل، استخدام قوالب موحّدة، تطبيق ضبط الإصدارات وإدارة الصلاحيات، حلقة تغذية راجعة (feedback loop)، ومراجعة/تحديث التوثيق بانتظام.

إدارة الأصول (Asset Management) — الجرد: تسجيل وصف الأصل، تاريخ الشراء، سجل الخدمة، الحالة، والموقع؛ تحديث التوثيق بانتظام؛ اعتماد أدوات برمجية لإدارة الأصول؛ وتطبيق ضوابط وصول صارمة على توثيق الجرد.

اكتشاف الأجهزة والمراقبة

Host Discovery and Monitoring

Network Discovery: تحديد أجهزة وخدمات الشبكة، لإدارة الشبكة والتدقيق الأمني. أدوات: Nmap, AngryIP, PRTG.

تقنيات فحص Nmap:

  • Basic Scans: الإجراء الافتراضي يرسل ping وحزم TCP ACK للمنافذ 80 و443، إضافة لعمليات مسح ARP وND على الشبكات المحلية.
  • Host Discovery: خيار -sn يكتشف الأجهزة بدون مسح المنافذ.
  • Service and OS Detection: يحدد الخدمات ونظام التشغيل العامل على المضيف.
  • Stealth Scans: لتفادي الاكتشاف وتحديد المضيفين غير المستجيبين.
CDP (Cisco Discovery Protocol)LLDP (Link Layer Discovery Protocol)
الملكيةأداة خاصة بـCiscoبروتوكول قياسي IEEE
الوظيفةيكتشف كيفية اتصال الأجهزة، نظام التشغيل، وعناوين IPنفس الوظيفة، لكن قياسي عبر الموردين
النطاقمعلومات من أجهزة CDP المتصلة مباشرة فقطمعلومات من كل أجهزة LLDP المتصلة مباشرة

Performance Monitoring: يتتبع سرعة وكفاءة الشبكة عبر مقاييس (bandwidth, throughput, CPU/memory, storage, latency, response time, error rate)، إنشاء خط أساس (baseline) من القيم التاريخية للمقارنة، وتنبيهات عند تجاوز العتبات (threshold alerts).

Availability Monitoring

يتحقق أن أجهزة وخدمات الشبكة تعمل ومتاحة عند الحاجة — اكتشاف مبكر للانقطاع، منع تأثير أوسع، استقرار الشبكة، وتحسين أداء السيرفر.

Configuration Monitoring

يتحقق أن كل أجهزة الشبكة بحالة معروفة — مقارنة الإعداد الحالي بـbaseline/golden configuration، إعداد الإنتاج (production)، والإعداد الاحتياطي (backup).

SNMP — بروتوكول إدارة الشبكة البسيط

Simple Network Management Protocol

SNMP: يعمل في طبقة Application، ويستخدم منفذي UDP 161/162.

وظائفه: مراقبة أجهزة الشبكة، اكتشاف أعطال الشبكة، وضبط الأجهزة عن بُعد.

الـManager يطلب/يضبط بيانات من الـAgent (Get/Set)، بينما الـAgent يبادر بإرسال Trap فور حدوث عطل دون انتظار طلب.

مكونات SNMP:

  • SNMP Manager (NMS): نظام مركزي لمراقبة الشبكة، يُعرف أيضًا بـNetwork Management Station.
  • SNMP Agent: وحدة برمجية على الأجهزة المُدارة (راوترات، سويتشات)، تحتفظ بمعلومات بقاعدة بيانات.
  • MIB (Management Information Base): مجموعة هرمية من معلومات الموارد المُدارة، منظّمة بفئات (system, interface, IP...).

رسائل SNMP

الرسالةالوظيفة
GetRequestاسترجاع بيانات من الـagents
GetNextRequestالحصول على قيمة متغيّر تالٍ (لإدخالات الجداول)
SetRequestضبط قيمة عنصر معيّن
Responseتأكيد نجاح ضبط القيمة
Trapيُرسَل من الـagent عند حدوث عطل
InformRequestمثل Trap لكن مع تأكيد استلام

أمان SNMP:

  • SNMPv2c: تجنّبي إرسال community strings نصية صريحة عبر الشبكة، استخدمي strings معقدة وليست الافتراضية، وقيّدي العمليات عبر ACLs لعناوين معروفة.
  • SNMPv3: يوفّر تشفيرًا ومصادقة قوية للمستخدم، باستخدام قوائم أسماء مستخدمين وصلاحيات بدل الـcommunity strings.
  • أوضاع المصادقة: authNoPriv (مصادقة بدون تشفير) وauthPriv (مصادقة مع تشفير باستخدام بيانات المستخدم).

إدارة الأحداث — Event Management

Network Device Logs · Syslog · SIEM

سجلات أجهزة الشبكة: مصادر بيانات لمراقبة الشبكة، استكشاف الأخطاء، والتدقيق الأمني. أنواعها: System Logs، Application Logs، Audit Logs، Performance/Traffic Logs.

استخدامات السجلات: تحديد مشاكل الشبكة وتحسين الأداء، تتبع الوصول غير المصرح به والانتهاكات (أمان/امتثال)، ومراجعة دورية مع تخزين آمن للسلامة والاستخدام الجنائي.

Log Collectors: تمركز وتبسيط إدارة سجلات الشبكة، عبر تجميع بيانات السجلات في مستودع واحد — الفوائد: إدارة مركزية، كفاءة، وقابلية التوسع.

Syslog: بروتوكول قياسي لإرسال رسائل السجل، يستخدم منفذ UDP 514، له PRI Code ومرونة عالية — منتشر جدًا ويسهّل التكامل بين الأنظمة.

ترتيب أولوية الأحداث والتنبيهات: تصنيف الأحداث من Emergency (0) إلى Debug (7) حسب الأهمية، والتنبيهات الآلية تُطلَق حسب شدة الحدث/العتبات/الشذوذ — يمنع الغرق بتنبيهات غير حرجة ويحدد أولوية الأحداث الحرجة.

تصاعديًا من الأخطر (يسار): 0 Emergency · 1 Alert · 2 Critical · 3 Error · 4 Warning · 5 Notice · 6 Informational · 7 Debug (الأقل أهمية).

SIEM (Security Information and Event Management): يحلل تنبيهات الأمان من التطبيقات وأجهزة الشبكة لحظيًا، يدمج إدارة معلومات الأمان (SIM) وإدارة أحداث الأمان (SEM).

وظائفه الأساسية: تجميع السجلات (Log Aggregation)، ربط الأحداث (Event Correlation)، والتنبيه (Alerting).

الفوائد: رؤية لحظية، اكتشاف واستجابة للتهديدات، إدارة الامتثال، تحسين وضع الأمان، وتقليل وقت الاستجابة للحوادث.

التقاط وتحليل الحزم

Packet Capture and Analysis

Packet Capture: تسجيل ترافيك الشبكة للتحليل واستكشاف الأخطاء، باستخدام مكتبة libpcap مع إمكانية فلترة لالتقاط بيانات محددة. مثال أمر: tcpdump -i eth0

أدوات تحليل الحزم: tcpdump · Wireshark · ngrep — تُستخدم لتشخيص المشاكل أو مراقبة صحة الشبكة.

تقنيات تحليل الالتقاط:

  • أهداف التحليل: فهم تدفق الترافيك، تحديد سوء الإعداد، واكتشاف الشذوذ.
  • ميزات Wireshark: فحص الرأس والحمولة إطارًا بإطار، واستخدام Follow TCP Stream لإعادة تركيب بيانات الجلسة.
  • أدوات إحصائية: Conversations، Protocol Hierarchy، وتحليل الترافيك.
MODULE 8 · LESSON 8.6

مراقبة الترافيك — Traffic Monitoring

Flow Data · Bandwidth Management · Traffic Shaping

Traffic Monitoring: مراقبة وتحليل مستمر لتدفق الترافيك عبر الشبكة لضمان الأداء والأمان الأمثل — يحدد اتجاهات حجم الترافيك، يراقب الأداء لاكتشاف الشذوذ، ويساعد بتخطيط السعة وتعديلات تصميم الشبكة.

مشاكل الأداء الشائعة: فقدان الحزم والتأخير والـjitter (يؤثر على جودة الخدمة QoS)، اختناقات bandwidth تُبطئ نقل البيانات، عتاد شبكة سيء الإعداد، وبنية تحتية قديمة.

Flow Data: معلومات مستخرَجة من حزم البيانات تعطي رؤية عن تدفق الترافيك — تشمل عناوين IP المصدر/الوجهة، أحجام الحزم، والطوابع الزمنية. ضرورية لتحليل الأداء واستكشاف الأخطاء، وتُستخدم في تحديد أنماط الترافيك واكتشاف الشذوذ.

أدوات اختبار الترافيك: تطبيقات تحاكي ترافيك الشبكة وتختبر أداء المكونات — تحدد اختناقات الشبكة وحدود السعة. تشمل مولّدات الحزم، محاكيات الشبكة، وأدوات قياس الإنتاجية. أمثلة: Wireshark, iperf, NetFlow Analyzer.

Bandwidth Management

تقنيات للتحكم بتدفق الترافيك لتحسين أو ضمان الأداء — تخصيص bandwidth بأولوية للخدمات الأساسية، منع الازدحام وضمان استخدام عادل، عبر rate limiting وtraffic policing.

Traffic Shaping

إعطاء أولوية للترافيك لضمان حصول التطبيقات الحرجة على bandwidth المطلوب — بتأخير الحزم لتنظيم التدفق وتقليل الازدحام. أدوات: QoS، DiffServ، وMPLS.

ملخص الوحدة 8: التوثيق والتغيير المُدار يمنع فوضى الشبكة؛ أدوات الاكتشاف (Nmap, CDP/LLDP) تحدد الأجهزة والاتصالات؛ SNMP يراقب ويضبط الأجهزة عن بُعد؛ السجلات وSIEM يجمّعان ويحلّلان الأحداث الأمنية؛ التقاط الحزم ومراقبة الترافيك يشخّصان مشاكل الأداء.
